# デッキ確率ラボ

60枚デッキ(初手7枚・サイド6枚)の確率を計算する、オフライン動作のウェブアプリです。

公開URL: https://nswtmk.github.io/crf/app/

スマホでこのURLを開き、ブラウザのメニューから「ホーム画面に追加」すると
アプリとして起動できます(PWA)。一度開けば以後はオフラインでも動きます。

## できること

| 機能 | 内容 |
|---|---|
| デッキ読み込み | 「4 カード名」形式のリストを貼り付けて解析。PTCGL書き出し形式にも対応 |
| マリガン率 | 初手7枚にたねポケモンが1枚も来ない確率 |
| カード別確率 | 初手・現在の条件・サイド落ち・全落ちの各確率 |
| コンボ成立確率 | 複数カードが同時に揃う確率をシミュレーションで算出 |
| 採用枚数の比較 | 1〜4枚それぞれの場合の確率を並べて比較 |
| デッキ診断 | 60枚チェック、4枚超過、たね不足、ドローサポート不足の警告 |

## 計算の中身

- **厳密計算**: 超幾何分布。log階乗表で計算しているため、`60C30` のように
  double の整数精度(2^53)を超える組み合わせ数でも精度が落ちません。
- **シミュレーション**: 山札60枚を実際にシャッフルし、
  先頭7枚=初手、次の6枚=サイド、その後ろから順にドロー、という手順を5万回繰り返します。
  マリガンの引き直しとサイド落ちが自然に反映されます。
- 「見えているカード」は初手7枚とドローの合計で、**サイドの6枚は引けない前提**です。

## 前提としているルール

先攻がターン1にドローするかどうかは、画面上で切り替えられるようにしてあります。
遊んでいるルールに合わせて選んでください。「追加ドロー」欄には、
サポートやグッズで上乗せして引いた枚数を手で入力します。

## 注意

種別・たね・ドローサポートの自動判定は入力を楽にするための目安にすぎません。
**計算結果はカード設定の内容に完全に依存します**ので、読み込んだあとに必ず確認してください。
とくに進化ポケモンは既定で「たね」が付いたままなので、外さないとマリガン率が実際より低く出ます。

カードのデータベースは持っていません。カード名と枚数はすべて利用者が入力します。

## 開発

ビルド手順はありません。素の HTML / CSS / JavaScript です。

```sh
# ローカルで開く (このディレクトリで)
python3 -m http.server 8000
# → http://localhost:8000/

# 計算まわりのテスト
node test.js
```

ファイルを更新したら `sw.js` の `CACHE` の値を上げてください。
そうしないと、すでに開いたことのある端末で古いキャッシュが残り続けます。
