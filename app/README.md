# TCG デッキツール

デュエル・マスターズ / ポケモンカード / 遊戯王 のデッキを扱う、オフライン動作のウェブアプリです。
2つの画面があります。

| 画面 | URL | 何をするか |
|---|---|---|
| 一人回し | https://nswtmk.github.io/crf/app/solo.html | 実際にデッキを回して手触りを確かめる |
| 確率ラボ | https://nswtmk.github.io/crf/app/ | 初手・コンボ成立・伏せ札の確率を計算する |

スマホでURLを開き、ブラウザのメニューから「ホーム画面に追加」するとアプリとして起動できます(PWA)。
一度開けば以後はオフラインでも動きます。デッキは2つの画面で共有されます。

## カードのデータベースは持っていません

カード名・枚数・種別はすべて利用者が入力します。
カードの効果も解決しません。何をどこに動かすかは人間が決め、アプリはゾーンの管理・
シャッフル・ドローだけを引き受けます。実物のプレイマットの代わりだと思ってください。

この作りにしているのは、カードプールもルールも頻繁に変わるためです。
アプリ側が中途半端なカード知識を持つと、古い情報のまま間違った答えを出します。

## 一人回し (solo.html)

- ゲームを選ぶとゾーン構成・初手枚数・伏せ札の枚数が切り替わります
- カードをタップすると移動先を選べます(ゾーン / 墓地 / 山札の上・下 など)
- 「サーチ」で山札の中身を見て手札に加えられます。閉じると自動でシャッフルします
- 伏せ札(サイド・シールド)は裏向きで、「中身を見る」で確認できます
- 1手ずつ「戻す」で取り消せます
- **記録**: 各回を「まわった / まわらなかった」で残すと、試行回数・成功率・
  平均マリガン回数・成功時の平均ターンが積み上がります

### ゲームごとの初期値

| | デッキ | 初手 | 同名 | 伏せ札 | 別の山 |
|---|---|---|---|---|---|
| ポケモンカード | 60 | 7 | 4 | サイド 6 | — |
| デュエル・マスターズ | 40 | 5 | 4 | シールド 5 | 超次元・GR |
| 遊戯王 | 40〜60 | 5 | 3 | — | エクストラ 15 |

`エクストラデッキ` `超次元` の見出しの下に書いたカードは別の山として扱い、
山札にも確率計算にも混ぜません。

## 確率ラボ (index.html)

- **マリガン率** — 初手に条件を満たすカードが来ない確率(ポケカのみ)
- **カード別確率** — 初手 / 現在の条件 / 伏せ札落ち / 全落ち
- **コンボ成立確率** — 複数カードが同時に揃う確率
- **採用枚数の比較** — 1〜4枚それぞれの確率を並べる
- **デッキ診断** — 枚数、同名制限、たね不足、ドローソース不足

### 計算の中身

- **厳密計算**: 超幾何分布。log階乗表で扱うため、`60C30` のように
  double の整数精度(2^53)を超える組み合わせ数でも精度が落ちません。
- **シミュレーション**: 山札を実際にシャッフルし、先頭が初手、次が伏せ札、
  その後ろから順にドロー、という手順を5万回繰り返します。
  マリガンの引き直しと伏せ札が自然に反映されます。
- デッキ枚数は定数ではなく、読み込んだメインデッキの実際の枚数を使います。

## 前提としているルール

先攻がターン1にドローするかは画面上で切り替えられます。ゲームごとの初期値は
入れてありますが、私の記憶違いもあり得るので、実際に遊んでいるルールに
合わせて直してください。一人回しの「ルールの調整」からは初手枚数・伏せ札の枚数・
マリガン方式も変えられます。

種別やフラグの自動判定は入力を楽にするための目安にすぎません。
**計算結果はカード設定の内容に完全に依存します**ので、読み込んだあとに必ず確認してください。
とくにポケカの進化ポケモンは既定で「たね」が付いたままなので、外さないと
マリガン率が実際より低く出ます。

## 開発

ビルド手順はありません。素の HTML / CSS / JavaScript です。

```sh
# ローカルで開く (このディレクトリで)
python3 -m http.server 8000

# 確率計算とデッキ解析のテスト (55件)
node test.js
```

| ファイル | 役割 |
|---|---|
| `deck.js` | ゲーム定義・デッキリストの解析・共有の保存処理 |
| `app.js` | 確率ラボ |
| `solo.js` | 一人回し |
| `test.js` | 検証。シミュレーションが超幾何分布の理論値と一致することを含む |

ファイルを更新したら `sw.js` の `CACHE` の値を上げてください。
そうしないと、すでに開いたことのある端末で古いキャッシュが残り続けます。
