# 足あと地図

行った場所を地図に記録し、**まだ行っていない場所を霧で覆って**見せるウェブアプリです。

公開URL: https://nswtmk.github.io/crf/map/

スマホでこのURLを開き、ブラウザのメニューから「ホーム画面に追加」するとアプリとして
起動できます(PWA)。一度開けば以後はオフラインでも動きます。

## できること

- **記録する** — 「いまここに記録」で現在地を、「地図で指定」で任意の場所を記録
- **写真とメモ** — 1件につき何枚でも。写真は長辺1600pxに縮めて保存します
- **写真の位置を使う** — 写真に位置情報があれば読み取り、その場所に合わせられます。
  昔撮った写真から後追いで記録を埋められます
- **未踏エリア** — 地図をマス目に区切り、行ったマスだけ霧が晴れます
- **記録の一覧** — 件数・踏破マス数・おおよその面積・写真枚数
- **持ち出し** — JSON で書き出し / 読み込み

## 共有機能 (任意)

初期状態では**すべて端末の中だけ**で動きます。設定すると、フォローと公開範囲が使えます。
準備の手順は [SETUP.md](./SETUP.md) にあります。

### 公開範囲

記録ごとに3つから選びます。**既定は「自分だけ」**です。

| | どうなるか |
|---|---|
| 🔒 自分だけ | **サーバーに送りません。** 端末の中だけに残ります |
| 👥 友達だけ | おたがいにフォローしている相手だけが見られます |
| 🌏 全体に公開 | 誰でも見られます |

あとから「自分だけ」に戻すと、サーバー側からも消えます。

### 友達

**おたがいにフォローすると友達**になります。片方向のフォローだけでは相手の
「友達だけ」の記録は見えません。勝手にフォローするだけで中身が見えてしまわないためです。

### アイコン

写真を選ぶと、正方形の中央を切り抜いて256pxに縮めてから保存します。
写真を設定しない間は絵文字と背景色が使われます。

**アイコンは誰にでも見えます**(プロフィール自体が誰でも読めるため)。
顔や自宅が写った写真は避けてください。

### 友達の新着を知らせる

友達が記録すると、地図の右側に🔔と件数が出ます。押すと一覧が開き、
選ぶとその場所へ飛びます。設定で切れます。

「端末の通知を許可する」を押すと、**アプリを開いているあいだ**は端末の通知も出ます。

> **アプリを閉じているあいだは届きません。** 閉じていても届く通知には、
> 誰かが記録した瞬間にサーバーから送信する仕組みが要ります。
> iPhone では、ホーム画面に追加したアプリなら技術的には可能です(iOS 16.4以降。
> Safari のタブでは不可)。必要なら作れますが、まだ入れていません。

新着の判定は「投稿された時刻」で行います。訪問日時は過去に遡って書けるので、
それを使うと古い日付で投稿されたものを見落とします。

### 通報とブロック

他人の記録から通報とブロックができます。ブロックすると、おたがいの記録が見えなくなり、
フォローも外れます。解除しても友達関係は戻りません。

### 守り方

公開範囲の判定は**データベース側の行レベルセキュリティ**が行います
([schema.sql](./schema.sql))。アプリの画面で出し分けているのではないので、
通信を直接叩かれても、見えないものは見えません。

## データはすべて端末の中だけにあります

記録も写真も、この端末のブラウザの中(IndexedDB)にだけ保存されます。
**どこにも送信していません。** サーバーもアカウントもありません。

裏を返すと、**ブラウザのデータを消すと記録も消えます。**
機種変更でも引き継がれません。設定画面から**ときどき書き出して保管してください。**

書き出したファイルは、同じアプリの「読み込む」で戻せます。「足す」と「入れ替える」を選べます。

## 未踏エリアの決め方

地図を Web メルカトルのタイル座標で正方形のマスに区切り、記録した地点が入るマスを
「踏破ずみ」として霧を消します。マスの細かさは設定で変えられます。

| 設定 | 東京あたりでのマスの大きさ |
|---|---|
| とても粗い | 約 4.0km 四方 |
| 粗い | 約 2.0km 四方 |
| ふつう(初期値) | 約 1.0km 四方 |
| 細かい | 約 500m 四方 |
| とても細かい | 約 250m 四方 |

メルカトル図法なので、緯度が高いほどマスは実距離で小さくなります。

「訪問した場所の周り1マスも踏破ずみにする」を入れると、1点の記録で3×3マスが晴れます。
点だけだと霧が晴れた実感が乏しいので、初期値では入れてあります。

## 地図について

タイルは [OpenStreetMap](https://www.openstreetmap.org/copyright) のものを使っています。
表示には出典の表記が必要なので、画面左下に常に出しています。

一度表示したタイルは端末にキャッシュされるので、行ったことのある範囲は圏外でも表示されます。
貯めすぎないよう1200枚を上限に、古いものから捨てます。

## 作りについて

地図の表示・ドラッグ・ピンチズームは `minimap.js` に自前で実装しています。
外部ライブラリを読み込まないので、CDN が落ちてもオフラインでも確実に動きます。

| ファイル | 役割 |
|---|---|
| `geo.js` | メルカトル変換・グリッド・距離の計算 |
| `exif.js` | JPEG の EXIF から撮影位置と日時を読む |
| `store.js` | IndexedDB への保存、書き出しと読み込み |
| `minimap.js` | 地図エンジン(タイル・操作・マーカー・霧の土台) |
| `app.js` | 画面の組み立て |
| `supa.js` | Supabase への接続 (fetch のみ。公式ライブラリは使わない) |
| `social.js` | プロフィール・フォロー・ブロック・同期 |
| `social-ui.js` | アカウントと友達の画面 |
| `schema.sql` | データベースの設計と行レベルセキュリティ |
| `mock-supabase.js` | 検証用の Supabase もどき (配信物ではない) |

### iPhone アプリにする

ホーム画面に追加すればアプリとして使えます。App Store で配信したい場合の手順と、
知っておくべき条件は [APPSTORE.md](./APPSTORE.md) にあります。

## 開発

ビルド手順はありません。素の HTML / CSS / JavaScript です。
外部ライブラリは地図も Supabase 接続も含めて一切読み込みません。

```sh
# ローカルで開く (crf/ の直下で)
python3 -m http.server 8099
# → http://localhost:8099/map/

# 計算まわり (ブラウザ不要、30件)
node test.js

# 公開範囲とフォロー (ブラウザ不要、43件)
node test-social.js

# 画面の動作確認。上のサーバを動かした状態で
npm i playwright-core
node test-browser.js        # 地図と記録 (34件)
node test-social-ui.js      # 共有まわり (37件)
```

`test-social.js` と `test-social-ui.js` は `mock-supabase.js` を自前で立てます。
このモックは `schema.sql` と**同じ見える条件**を実装しているので、
「自分だけの記録が外に出ないか」「片方向フォローで友達限定が見えないか」を
実際の通信で確かめられます。

`test-browser.js` は地図タイルを差し替え、現在地と位置情報つき写真を擬似的に与えて、
記録・霧の消え方・ピンの位置・書き出しと読み込みまでを通しで確認します。

ファイルを更新したら `sw.js` の `SHELL` の版を上げてください。
そうしないと、すでに開いたことのある端末で古いキャッシュが残り続けます。

**このリポジトリは `gh-pages` ブランチから配信されています。**
`main` に入れただけでは公開されないので注意してください。
