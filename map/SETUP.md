# 共有機能をつかう準備

フォローや公開範囲を使うには、記録を預ける先が要ります。ここでは無料で始められる
**Supabase** を使います。作業は15分ほど、費用はかかりません。

**この設定をするまで、アプリはこれまでどおり端末の中だけで動きます。**
共有を使わないなら、以下は必要ありません。

---

## 1. Supabase のプロジェクトを作る

1. https://supabase.com を開き、GitHub アカウントなどでサインアップします
2. **New project** を押します
3. 入力するもの
   - **Name**: 何でも構いません(例 `trailmap`)
   - **Database Password**: 自動生成のままで構いません。**この画面を閉じる前に控えてください**
   - **Region**: `Northeast Asia (Tokyo)` を選ぶと日本からの反応が速くなります
4. **Create new project** を押し、準備が終わるまで1〜2分待ちます

## 2. 設計を流し込む

1. 左のメニューから **SQL Editor** を開きます
2. **New query** を押します
3. このフォルダの `schema.sql` の**中身を全部**コピーして貼り付けます
4. **Run** を押します

`Success. No rows returned` と出れば成功です。何度実行しても同じ結果になるので、
やり直しても問題ありません。

これで作られるもの:

| | 中身 |
|---|---|
| `profiles` | ニックネームとアイコン |
| `follows` | 誰が誰をフォローしているか |
| `visits` | 共有する記録(「自分だけ」はここに入りません) |
| `likes` | いいね |
| `photos` | 記録に添える写真の置き場所 |
| `avatars` | プロフィールのアイコン(誰でも読めます) |

あわせて**行レベルセキュリティ**が設定されます。これが公開範囲の本体です。
「自分のもの」「全体公開」「相互フォローの相手のもの」以外は、
データベースが読ませません。アプリの画面で隠しているのではありません。

## 3. 接続先を控える

1. 左下の歯車 → **Project Settings** → **API** を開きます
2. 次の2つを控えます
   - **Project URL**(`https://xxxxxxxx.supabase.co` の形)
   - **anon public** キー(`eyJ...` で始まる長い文字列)

> **anon キーは公開ページに置いて構わないもの**です。これだけでは何も読めません。
> 実際の保護は手順2で入れた行レベルセキュリティが行います。
> 一方 **service_role** キーは全部を素通しするので、**絶対にアプリに入れないでください。**

## 4. アプリにつなぐ

1. アプリを開き、右上の **ログイン** を押します
2. 手順3の2つを貼り付け、**つなぐ** を押します
3. メールアドレスとパスワード(6文字以上)を入れて **新規登録**
4. ニックネームを決めて **プロフィールを保存**
5. アイコンは **写真を選ぶ** から。正方形に切り抜いて保存します。
   写真を使わない場合は「写真を使わず絵文字にする」を開いてください

## 5. メール確認の設定(任意)

初期状態では、登録時に確認メールが届きます。自分ひとりで試すあいだは切っておくと楽です。

**Authentication** → **Providers** → **Email** → **Confirm email** をオフ。

人に配るときは**オンに戻してください。** 他人のメールアドレスで勝手に登録される
のを防ぐためです。

## 使い方

### 公開範囲

記録するとき、3つから選びます。**既定は「自分だけ」**です。

| | どうなるか |
|---|---|
| 🔒 自分だけ | サーバーに送りません。端末の中だけに残ります |
| 👥 友達だけ | おたがいにフォローしている相手だけが見られます |
| 🌏 全体に公開 | 誰でも見られます |

あとから「自分だけ」に戻すと、サーバー側からも消えます。

### 友達

**おたがいにフォローすると友達**になります。片方向のフォローだけでは、
相手の「友達だけ」の記録は見えません。勝手にフォローするだけで
中身が見えてしまわないようにするためです。

### 通知

友達が記録したとき、および自分の記録にいいねが付いたときに🔔へ件数が出ます。
「⋯」→ 通知 から切り替えられます。

「端末の通知を許可する」を押すと、**アプリを開いているあいだ**は端末の通知も出ます。
**閉じているあいだは届きません。** 閉じていても届くようにするには、
記録された瞬間にサーバーから送信する仕組み(Supabase の Edge Function)が別途要ります。

iPhone で通知を使うには、**ホーム画面に追加したアプリとして開いてください。**
Safari のタブでは通知を出せない決まりになっています(iOS 16.4以降で対応)。

### 気をつけること

位置の記録は、続けるほど**自宅や職場、生活圏が分かる情報**になります。
「全体に公開」は、その一点だけでなく積み重ねが読まれることを踏まえて選んでください。
迷ったら「自分だけ」か「友達だけ」で十分です。

### 写真

写真はいまのところ**端末の中だけ**に置いています。共有した記録にも写真は付きません。
共有したい場合は言ってください(置き場所と読み取り権限は `schema.sql` に用意済みです)。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「つなぐ」で URL の形が違うと言われる | `https://` から始まり `.supabase.co` で終わる形か |
| 登録できるがログインできない | 手順5の確認メールが届いていないか |
| 友達の記録が出てこない | **おたがいに**フォローしているか(片方向では見えません) |
| 「row violates row-level security policy」 | 手順2の SQL が流れているか。もう一度 Run して構いません |
| 何も共有されない | 記録の公開範囲が「自分だけ」のままになっていないか |

## つなぐのをやめたいとき

アカウント画面の **接続先の設定を消す** を押します。
**端末の記録は消えません。** サーバー側のデータも残るので、
完全に消すなら Supabase の画面でプロジェクトごと削除してください。
